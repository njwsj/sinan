# 行为基线用例清单

状态含义：`部分` 表示当前有局部代码但不能声称兼容；`缺失` 表示没有对应公开能力；`待测` 表示必须连接参考服务才能锁定实际响应。

|---:|---|---|---|---|

| 2 | Prompt 为空 | 有，422 | 部分 | 空值与最短长度 |
| 3 | Prompt 过长 | 有约束待测 | 无声明 | 实际边界 |
| 4 | 普通聊天输入 | 有，mode/chat | 缺失 | 路由与事件 |
